## Overview
This interactive Power BI dashboard provides dynamic insights into global automotive sales performance, revenue trends, and key order metrics.

## Key Features
* **Executive KPIs**: Tracking Total Orders, Total Revenue, Total Quantity, and Average Price.
* **Interactive Slicers**: Multi-dimensional filtering by Year and Product Line.
* **Sales Trends & Breakdown**: Time-series revenue analysis, deal size distributions, and country-level performance rankings.
